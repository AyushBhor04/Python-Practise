# Python Practice Repository

A structured collection of Python practice programs covering fundamental programming concepts and Object-Oriented Programming (OOP).  
This repository is intended for learning, revision, hands-on coding practice, and strengthening problem-solving skills.

---

## Repository Overview

The repository includes topic-wise Python programs starting from basic syntax to advanced OOP concepts.  
Each file focuses on a specific concept with simple and practical examples for better understanding.

---

## Topics Covered

- Python Basics
- Variables and Data Types
- Input and Output Operations
- Operators
- Conditional Statements
- Loops (`for` and `while`)
- Functions
- Strings
- Lists
- Tuples
- Sets
- Dictionaries
- Object-Oriented Programming (OOP)

## File Description

| File Name | Description |
|------------|-------------|
| `basic.py` | Introduction to Python syntax and basic programs |
| `conditional_statements.py` | Programs using if, elif, and else statements |
| `dictionaries.py` | Dictionary creation, access, and methods |
| `for_loop.py` | Iteration using for loops |
| `functions.py` | User-defined functions and parameters |
| `input_statement.py` | Taking user input and type conversion |
| `lists.py` | List operations and methods |
| `oops_1.py` | Basic OOP concepts such as classes, objects, constructors, and methods |
| `oops_2.py` | Advanced OOP concepts including inheritance, polymorphism, encapsulation, abstraction, and method overriding |
| `sets.py` | Set operations and built-in methods |
| `strings.py` | String handling and manipulation |
| `tuples.py` | Tuple operations and properties |
| `while_loop.py` | Programs using while loops |
